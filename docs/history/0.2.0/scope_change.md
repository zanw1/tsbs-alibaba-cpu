# 当前范围与审查记录

## 2026-09-07 范围调整

根据用户要求，取消原生 Alibaba 七指标数据集。当前只维护 `compatible` 和 `matched_tsbs`，包版本 0.2.0，数据格式版本 4。

已移除原生导出、原生解码、原生指标验证和七指标 schema。源索引只保留机器、时间和 CPU，不再缓存整个原始行。数据库回读改为两种保留视图的 SF1、全部 21 列。

原三视图数据和旧安装包均已归档，没有删除原始 CSV 或实验记录。此前的[深度审查](history/v3/deep_review.md)仅作历史记录；其中原生指标相关修复不再作为当前需求。

## 当前正确性合同

1. 兼容版 CPU 必须与原始 Alibaba 在对应机器和时间上精确一致。
2. 配对 TSBS 保留原 TSBS 参考记录，兼容版其他列必须与同一参考一致。
3. 缺失 CPU 在两侧同时排除并计数；缺测不填零或插值。
4. 查询目录检查参数、SQL、数量和两侧结果规模，空目录不能通过。
5. 数据可独立搬迁，不依赖原主项目或外部符号链接。
6. 构造失败不发布残缺版本，数据库清理失败不能记录为通过。

契约测试已调整到双视图目标，明确断言不生成 native。新版本的全量构造和验证记录位于当前 data/alibaba_day1，旧版本证据保留在归档目录。
